# Scrum Master vs Team Agile Coach

A single-file HTML slide deck, published to GitHub Pages. Open `index.html` directly, or visit the live site.

## Keyboard shortcuts

| Key | Action |
|---|---|
| `→` / `Space` / `Page Down` | Next slide |
| `←` / `Page Up` | Previous slide |
| `Home` | Jump to first slide |
| `End` | Jump to last slide |
| `1`–`9` | Jump to that slide number |
| `R` | Reset to slide 1 |
| `↓` | Reveal the next item (misconceptions slide only) |
| `↑` | Hide the last revealed item (misconceptions slide only) |
| `N` | Toggle the speaker notes panel |
| `B` | Toggle brand theme: Michelle ↔ Benefact |
| `T` | Toggle the thumbnail rail (has no visible effect in this standalone export; the rail only renders inside the claude.ai/design editor) |

Tap the left or right half of the slide to go back or forward on a touchscreen.

## Files

- `index.html` — the deck itself (self-contained: brand themes, animations, and presenter tools are all inlined)
- `support.js`, `deck-stage.js` — the slide-player runtime
- `_ds/` — Michelle's design-system tokens (fonts, colours, spacing) the deck reads
